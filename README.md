# Budget Tracker App

A simple budget tracking web application built during my software development bootcamp.

The app allows users to add income and expense transactions, view their balance, and track transaction history in a clean interface.

## Features

- Add income and expense transactions
- View total balance
- Track money in and money out
- Delete transactions
- Store data in browser local storage

## Tech Stack

- HTML
- CSS
- JavaScript

## Purpose

I built this project as part of my bootcamp to strengthen my understanding of:

- DOM manipulation
- JavaScript event handling
- Array methods
- Local storage
- Building interactive front-end applications

## How to Run

1. Download or clone the repository
2. Open `index.html` in your browser

## What I Learned

This project helped me practise building a small interactive application using JavaScript and improved my understanding of how to manage user input, update the UI dynamically, and persist data in the browser.
